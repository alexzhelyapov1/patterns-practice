**Бизнес-кейс: Система рендеринга графических уведомлений.**
Тебе нужно разработать каркас для GUI-библиотеки.
1. Создай интерфейс `Button` с методом `render()`.
2. Реализуй два типа кнопок: `WindowsButton` и `LinuxButton` (просто вывод текста в консоль).
3. Создай абстрактный класс `Dialog`, который содержит логику отрисовки окна, но делегирует создание кнопки (`createButton()`) своим наследникам.
4. Реализуй `WindowsDialog` и `LinuxDialog`.

**Условие:** Используй `std::unique_ptr`. Клиентский код должен вызывать метод `renderWindow()` у объекта `Dialog`, который внутри себя создает кнопку через фабричный метод и вызывает её `render()`.
