# 3. Задание: "Налоговый калькулятор"
**Бизнес-кейс:** Ты пишешь модуль для системы e-commerce. Тебе нужно вычислять итоговую стоимость корзины с учетом налогов разных стран.

**Условия:**
1. Создай три стратегии расчета налога:
   - `USA_Tax` (фиксированный налог 10%).
   - `EU_Tax` (фиксированный налог 20% + фиксированный сбор за импорт $5).
   - `Zero_Tax` (налог 0%, для беспошлинных зон).
2. Реализуй класс `TaxContext`, который принимает цену и применяет выбранную стратегию.
3. Используй **динамическую реализацию** (интерфейс и `std::unique_ptr`), так как страна покупателя может стать известна только в runtime после ввода адреса.
