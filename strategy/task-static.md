# 2. Задание на статическую стратегию
**Бизнес-кейс:** Ты разрабатываешь высокопроизводительный движок для обработки массивов чисел. Тебе нужно форматировать вывод данных в разных стилях для логов.

**Твоя задача:**
1. Создай концепт `Formatter`, который требует наличия метода `std::string format(const std::vector<int>& data)`.
2. Реализуй две статические стратегии:
   - `CsvFormatter`: возвращает строку, где числа разделены запятыми (`1,2,3`).
   - `JsonFormatter`: возвращает строку в формате JSON массива (`[1, 2, 3]`).
3. Создай шаблонный класс `DataReporter<Formatter>`, который владеет вектором данных и имеет метод `void print()`, вызывающий выбранный форматтер.
4. **Усложнение:** Используй `std::string_view` или `std::stringstream` для эффективной сборки строки.

**Почему это важно:** В статическом варианте компилятор заинлайнит вызовы форматтера, и ты получишь нулевые накладные расходы на полиморфизм.
